# Task Manager Backend API (`api`)

Backend Node.js + Express + MongoDB + Nodemailer cho **Case Study 2: Ứng dụng Quản lý và Giao công việc nhóm**.

## Cài đặt & Chạy
1. Sao chép `.env.example` thành `.env` và điền thông tin kết nối `MONGODB_URI`, `JWT_SECRET`, `SMTP_*`.
2. Cài đặt thư viện:
   ```bash
   npm install
   ```
3. Chạy server:
   ```bash
   npm run dev
   ```
